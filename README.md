# Online Retail SQL Analytics Project

## Overview

This project demonstrates my SQL skills from beginner to advanced level using a realistic online retail database.

The project covers:

- Database Design
- SQL Table Creation
- Data Insertion
- Basic Queries
- Joins
- Aggregate Functions
- Subqueries
- Views
- Window Functions
- Stored Procedures
- Triggers
- Query Optimization
- Business Analytics Reporting

---

## Business Scenario

An online retail company sells products to customers across multiple cities.

Management wants insights into:

- Revenue
- Customer Spending
- Product Performance
- Sales Trends
- Inventory Levels

This project was created to answer those business questions using SQL.
